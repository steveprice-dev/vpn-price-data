# Changelog

All notable dataset and contract changes are recorded here.

## 0.2.0 - 2026-08-09

- Expand the pre-observation population from 20 to 25 providers.
- Add Amnezia Premium, OVPN, Mysterium VPN, AzireVPN, PrivateVPN, and VPN Unlimited;
  move PrivadoVPN from the original panel to the permission-required watchlist.
- Exclude TorGuard, PrivadoVPN, FastestVPN, and X-VPN from unattended
  collection because their published terms restrict the required automation.
- Document the written-permission or official-feed route by which an excluded
  provider can be reconsidered.
- Preserve the existing public-results/private-evidence boundary.

## 0.1.0 - 2026-08-08

- Define the observation contract and explicit evidence states.
- Establish the 20-provider initial population and watchlist.
- Add collection, renewal, field, and manual verification methods.
- Add deterministic JSON, CSV, checksum, and release-manifest validation.
- Establish the private-evidence/public-results publication boundary.
